## 2. Reporting a Vulnerability
Vulnerabilities can be reported via:
- Email to Abir Maheshwari at abhirsxn@gmail.com
- Private GitHub security advisory on the AbirQu repository

Response timeline:
- Acknowledgment within 48 hours
- Initial assessment within 7 days
- Coordinated disclosure after fix deployment
